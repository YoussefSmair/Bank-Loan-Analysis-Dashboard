# 🏦 Bank Loan Analysis Dashboard

An interactive **Bank Loan Analysis Dashboard** designed to provide a clear overview of loan applications, funded amounts, received amounts, interest rates, loan quality, and borrower information.

The dashboard helps users explore loan performance, identify trends, and analyze important factors related to loan applications.

---

## 📊 Dashboard Preview


### 1. Summary

The **Summary** page provides a high-level view of the most important loan KPIs, including:

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Good Loan vs. Bad Loan
* Loan Status
* Loan Quality

## 🎯 Project Objectives

The main objectives of this dashboard are to:

* Monitor overall loan performance.
* Analyze loan application trends.
* Compare good loans and bad loans.
* Understand loan distribution by purpose and term.
* Analyze borrower characteristics.
* Provide an interactive interface for exploring loan data.
* Present complex financial data in an easy-to-understand format.

---

## 🔍 Key Insights

The dashboard focuses on several important business questions:

* How many loan applications were received?
* How much was funded through loans?
* How much was received back?
* What is the average interest rate?
* What percentage of loans are considered good or bad?
* Which loan purposes have the highest number of applications?
* How are loans distributed across different terms?
* How does home ownership affect loan applications?
* Which states have higher loan activity?

## 💡 Project Purpose

This project was created as a **Data Analysis and Business Intelligence portfolio project**, focusing on transforming loan data into meaningful business insights through an interactive dashboard.

The goal is to make financial data easier to understand and support better data-driven decision-making.
